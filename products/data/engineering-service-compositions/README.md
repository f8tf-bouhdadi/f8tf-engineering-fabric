# F8TF Data Engineering Service Compositions

This directory exposes qualified compositions of autonomous Data Engineering
Services.

A composition is an engineering object with its own:

- composition identity;
- participating Engineering Services;
- service bindings;
- information correspondences;
- invariants;
- end-to-end guarantees;
- acceptance criteria;
- verification rules;
- composition evidence.

No Data Engineering Service Composition is currently exposed publicly.

Qualified compositions may be published only after their public service
boundary, guarantees, verification material and delivery have been reviewed
for external release.
