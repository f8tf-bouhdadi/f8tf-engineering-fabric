# F8TF Products Model

## Purpose

Engineering Products realize one or more Engineering Capabilities.

Products are not the starting point of the customer journey.
They implement capabilities that address recurring engineering concerns.

## Product Contract

Each Engineering Product answers five questions.

### 1. What is it?

A concise description of the product.

### 2. Which Engineering Capability does it realize?

Reference the Engineering Capability.

### 3. Which Engineering Concerns does it address?

Reference the dominant engineering concerns.

### 4. How is it evaluated?

Reference the Engineering PoC.

### 5. Where is the evidence?

Reference public guarantees and engineering evidence.

## Navigation

Engineering Concern
→ Engineering Solution
→ Engineering Capability
→ Engineering Product
→ Engineering PoC
→ Engineering Guarantees
→ Engineering Evidence
